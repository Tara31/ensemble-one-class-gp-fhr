# Data Instructions

This project uses a public fetal heart rate dataset:

https://preana-fo.ece.stonybrook.edu/database.html

Due to data size and privacy considerations, the dataset is not included in this repository.

## Expected input

A tabular feature file (e.g., Excel) with:
- Feature columns
- A label column named `cat`
    - CAT-1 → healthy
    - CAT-3 → pathological
